# ERP — Metalúrgica Vértice

## Sobre o projeto
Este é um projeto acadêmico desenvolvido em grupo durante o curso de Engenharia de Software na UNICID.

O objetivo foi planejar um sistema ERP para uma metalúrgica fictícia, permitindo organizar informações da empresa e acompanhar os produtos desde a matéria-prima até a venda.

## Principais funcionalidades propostas
- Cadastro de produtos e fornecedores.
- Controle de matéria-prima e estoque.
- Acompanhamento da produção.
- Registro de vendas e clientes.
- Rastreabilidade dos produtos por lote.

## Tecnologias e materiais
- SQL para estruturação do banco de dados.
- Diagrama Entidade-Relacionamento (DER).
- Documentação e modelagem do sistema.

## Minha participação
Participei de várias etapas do projeto junto com meu grupo, ajudando na organização das informações, na documentação e na revisão da estrutura do banco de dados.

Foi uma experiência importante para entender melhor como funciona o planejamento de um sistema e aprender a trabalhar em equipe.

## Desenvolvimento
O projeto faz parte das atividades da faculdade e reúne documentos, diagramas e arquivos relacionados à modelagem do ERP.
